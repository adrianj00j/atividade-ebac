## Objetivo do Projeto
Este projeto tem como objetivo aplicar os fundamentos da descoberta de dados (Data Discovery) utilizando estatística descritiva e visualização de dados. A base de dados contém informações sobre produtos, marcas e preços de um supermercado do Chile.

## 🛠️ Tecnologias Utilizadas
- **Python** 
- **Pandas** (Tratamento, Limpeza e Agrupamento de Dados)
- **Plotly Express** (Visualizações Interativas e Mapas)
- **Scipy / Numpy** (Cálculos estatísticos)
